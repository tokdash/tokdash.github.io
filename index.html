Get started

Up and running in 30 seconds

Python package, one command to install, one to set up. Your data never leaves your laptop.

  1. 1

    Install

    pipx install tokdash

  2. 2

    Setup

    Run tokdash setup. It configures a reversible, no-sudo background service and finds your CLI logs automatically.

  3. 3

    Done

    The wizard prints your dashboard URL, defaulting to http://127.0.0.1:55423.

Features

Everything you spend, made visible

From raw token counts to real dollars, drilled down to a single session.

Exact tokens, billed in real money

Input, output, and cache tokens per tool, model, and day, providing the real counts from your logs, turned into dollars by a built-in pricing database.

Report tab, ready to share

A week, month, or year-to-date report on a calendar-aligned window, with a day map, podiums for harness, model and project, hour and weekday rhythm, and PNG share cards.

Contribution heatmap

A GitHub-style calendar of your activity, featuring a 3D isometric view and an energy estimate to recolor days by kWh.

Session explorer

Drill into any session, grouped by project and across tools, to find exactly what ran up the cost.

Statusline integration

Surface live token and cost indicators right in your shell prompt while you work, with no need to switch windows.

17 themes, light & dark

Classic, Midnight, Terminal, Arcade and more, with system-preference detection, custom date ranges, and UI in six languages (English / 中文 / 日本語 / 한국어 / Español / Português).

One package, four views

One install ships the WebUI, the TUI, the macOS and Windows companion, and the shell statusline. Same data, whichever surface you are at.

Subscription quota tracking

Monitor remaining Codex, Claude Code, and Antigravity quotas. Track your consumption history, view usage graphs, and set custom update intervals in a single view.

Multi-server views

Add a Tokdash server for each machine in Settings. Any selection of them aggregates into one Overview, one Sessions list, one heatmap.

TUI

The whole dashboard, driven by the keyboard

Run tokdash tui and the Overview, Report and Quota tabs open inside your terminal, no browser required. Launched beside tokdash serve it reads the same local index and cache, so the two views never drift apart.

Multi-server

Every machine you code on, one total

Add a Tokdash server for your WSL box, your Mac, or a spare machine. Select any combination and every tab follows it, while quota stays grouped by the machine that owns it.

  • Combine or isolate

    Pick all servers or just one. Totals, charts and session lists follow the selection, and it sticks between visits.

  • Nothing to install to look

    A server is a URL you add in Settings. Each machine keeps its own logs, its own pricing overrides and its own credentials.

  • Quota stays per machine

    Subscription windows render under the server that owns them, so two machines on one Codex plan never blur into a single bar.

Companion app

Today's spend, one click away in your menu bar

Tokdash Companion is a native menu-bar (macOS) and tray (Windows) client for your local Tokdash service. Read-only and privacy-first, with no telemetry, and it talks only to the endpoint you configure.

Today's spend at a glance

Cost, tokens, and messages with active time, the % change vs yesterday, and your top tools and models ranked.

Quota bars with reset countdowns

Per-provider subscription windows show remaining quota and relative reset times, such as "resets in 19 minutes", with Codex reset credits called out.

Alerts you control

Opt-in low-quota notifications with your own thresholds, launch at login, and a UI in System / English / 简体中文 / 日本語 / 한국어 / Español / Português.

Private by design

No telemetry, nothing uploaded. The app only talks to the Tokdash endpoint you set, which is usually your own localhost service.

Download from GitHub Releases

On Windows, the Microsoft Store build is signed by Microsoft and updates itself. The macOS universal dmg and the Windows portable zip on GitHub Releases are unsigned, so Gatekeeper / SmartScreen will warn on first launch. Look for tags companion-v*.
